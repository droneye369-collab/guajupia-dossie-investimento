## Integridade da recuperação

O pacote inclui o ZIP original recuperado do Telegram (`guajupia_app_v8_en_dolar.zip`) e um registro das alterações finais de quinta-feira reaplicadas. Consulte `RECUPERACAO-20-08.md`.

## Responsabilidade dos números

Valores são referências de planejamento preservadas no projeto. Orçamentos, custos, câmbio, projeções de receita e valuation devem ser atualizados e validados antes de qualquer decisão financeira ou apresentação formal.
